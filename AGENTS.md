# Crescent City regional consumer

All implementation belongs in `docxology/region-intel`. This repository contains
only configuration, public regional evidence, a small shared-runner importer,
consumer acceptance and deployment workflows. Never copy shared methods here.
Use Bun and the frozen lockfile. Run `bun run validate`, `bun run pages:export`
and `bun run pages:validate -- .pages`. Live acquisition is separate acceptance.
Preserve source rights, corpus identity and upstream unavailable/stale states.
Follow the enclosing GitVault lease and storage rules.
