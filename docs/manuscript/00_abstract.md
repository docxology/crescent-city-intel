# Abstract {#sec:abstract}

Crescent City Intel is a regional deployment of region-intel for Crescent
City and Del Norte County, California. The deployment binds local
configuration to an immutable shared runtime and publishes a reviewed
municipal-code projection for offline static export. This report describes
how the deployment distinguishes source verification, release inputs, and
the generated site. The retained edition contains 245 article pages and
2,206 sections. The local audit checked the receipt's file digests,
identifier uniqueness, and count agreement across the projection,
manifest, and verification report. These checks concern a recorded
edition and have no bearing on the current legal text or availability of
live sources.
