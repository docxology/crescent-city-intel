# Deployment context {#sec:context}

A civic reference needs to say which edition a reader is searching and
which steps a maintainer verified. The upstream municipal-code service
identifies the Crescent City corpus as CR4919 [@ecode360crescent].
The public snapshot retains article and section identifiers so readers
can identify the material behind an exported result. The historical
verification receipt records the observation clock and the scope of the
source comparison.

Generic adapters, verification methods, and the static exporter belong
to the shared region-intel repository [@regionintelruntime]. This
deployment owns its civic identity, provider policy, runtime pin, and
reviewed release inputs. Its thin importer passes the deployment root
and command arguments to the shared runner. A pinned runtime is a code
reproducibility control; the edition receipt separately binds the public
input bytes.
