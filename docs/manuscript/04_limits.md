# Scope and limitations {#sec:limits}

The report concerns a recorded municipal edition. The proof of byte
identity can detect changes to the committed inputs. It cannot establish
the accuracy of an extraction or the present content of a source page.
The historical sampled comparison leaves unsampled current source
behavior unobserved. Readers should refer to the official municipal
source when they need current law.

The reviewed release projection and the raw local corpus have different
purposes. Static readers can search the published edition. Reproducing
the source article-set binding requires the accepted raw acquisition
inputs under local custody. The local checks did not collect live feeds,
run model services, deliver alerts, or verify the hosted site's
deployed bytes. Source rights and provider observation clocks remain
separate from the software license and the publication build clock.
