# Current project state

The Quadruplicate is a Bun/TypeScript municipal-code and civic-intelligence
platform with a bounded static public edition. The v3.1.0 operating contract
covers source custody, explicit gaps, finite acquisition, shared family/API
validation, private diagnostics, staged indexes and recoverable publication.
The [release acceptance receipt](release-acceptance.json) names measured checks
and snapshot identity: read its version, date and scope before attributing a
result to the current tree. A receipt for an older release does not certify a
later source change. [TODO.md](../TODO.md) is the only open item-level backlog;
[CHANGELOG.md](../CHANGELOG.md) is the only version history.

## Evidence and acquisition

Municipal article/section counts come from the selected edition manifest.
Retained raw HTML, extraction receipts, separately fetched section fragments and
exported section text have distinct hashes. Verification separates local
custody, current table of contents and a deterministic live sample. A live
mismatch, missing sample or incomplete edition cannot produce publication
eligibility. This establishes bounded source/extraction evidence, not universal
legal completeness or continuing remote currency.

The canonical source registry declares enabled producers and reference/discovery
boundaries. Reachability, parser success, collection units and geographic coverage
remain separate. Source health has stable identity and explicit `ok`, `empty`,
`unavailable` or `stale` states. Retrieval time does not freshen a retained
observation. `src/source_clocks.ts` declares per-monitor retrieval, observation
or product bases and validity windows; missing, invalid, future or expired
required primary timestamps cannot contribute current severity.

News, official meeting/archive records, YouTube transcripts, reference-only
Triplicate metadata, event discovery and twenty hazard monitors retain their
source boundaries. MyGov application catalogs are not issued permits; PacFIN
report catalogs are not measured landings; statewide fuel is not local pricing;
unestablished local AIS coverage stays unavailable. HMS density is qualitative,
with measured AQI/PM2.5 and numerical forecasts unknown unless supplied by an
actual product. `bun run source:coverage` projects bounded retained evidence and
registry identity without networking, credential inspection or output writes.

The meeting-document producer retains exact PDFs and native page-addressable
text with hashes, offsets and extraction uncertainty. County/archive gaps remain
explicit where observed responses do not establish usable records. Retained
lineage comparison validates raw/parsed custody before generating asymmetric
addition/removal/identity candidates. The
[dated local lineage receipt](evidence/lineage-local-2026-09-30.json) records a
real retained-to-current comparison with zero semantic change candidates and a
native proposed-policy negative control. Its proposal span establishes neither
an adopted City ordinance nor human legal review; legal dates remain null.

## Owned execution and retained state

Acquisition uses finite parent budgets, streamed wire/decoded caps, DNS/IP and
redirect policy, request-path robots evaluation and credential redaction. Direct
vector SDK responses are byte-bounded before JSON parsing, with finite admission,
deadline and caller cancellation. Owned child/process groups and the browser's
private pre-protocol launcher identity support bounded shutdown and dead-controller
recovery. Ambiguous directories and substituted process identities are preserved
rather than treated as cleanup authority.

Shared output-root and cancellation scopes travel through producers, caches and
steps. Same-root writers serialize with token-owned leases. Namespace admission
rejects intermediate symlinks before creating locks or recovering state. News,
government and Triplicate publish their source batch/health/seen state through
recoverable exact-byte transactions; history follows the committed batch. Corrupt,
linked or oversized retained seen/hash state cannot be silently replaced as an
empty baseline. YouTube retains transcript bytes before advancing seen state.

Weekly execution has one parent deadline, durable attempt/per-step archives,
explicit interruption and exact-byte completion publication. A cancelled or
killed run retains its incomplete evidence and preserves the prior completed
edition; cleanup remains owned before releasing the lease. Curation retries
reuse a retained successful summary only when exact source text, citations,
provider/model and prompt lineage match. Source-only, corrupt or ambiguous
receipts cannot suppress retry. Migration rollback restores reviewed original
bytes without inventing historic observation times.

Container profiles pin the application/runtime and optional backend images,
persist declared volumes, bound logs and expose degraded model/service readiness.
Scheduler plans escape arguments and manage only explicit owned files with SHA
and recovery journals. Native activation/deactivation is an explicit operator
boundary. Isolated restart/install/rotation fixtures do not establish a permanent
host service or recurring successful delivery.

## Runtime, readers and private state

Structural OpenAPI is the HTTP method/authentication/input/response authority.
Shared versioned artifact schemas enforce exact supported family types, versions,
counts, confidence, clock and public-URL invariants at loaders, annotated API
responses and Pages boundaries. Legacy health envelopes have an explicit strict
read migration; missing clocks and review dates are never invented. Generated
configuration/export/HTTP inventories derive from source syntax and structural
OpenAPI; filename-specific drift guards exclude historical CHANGELOG and frozen
ISA. Dynamic configuration expressions remain disclosed rather than evaluated.

Authentication/quota identity uses the socket peer and declared trusted-proxy
policy. Request/body/history bounds and admission prevent unbounded expensive
work. Public metadata excludes secrets, raw provider URLs and private paths.
A truly absent/empty corpus can start the GUI with empty search and unavailable
code statistics; malformed manifests, orphan core files, missing declared
articles and linked namespaces fail rather than masquerading as fresh empty data.
The GUI has explicit ESM dependencies and one mutable state owner, scoped inert
rendering, cancellation/latest-request ownership, focus restoration, keyboard
navigation and live loading/error announcements. Primary-API desktop/mobile
reader journeys and security journeys have distinct native receipts; those tests
do not establish universal accessibility or actual upstream availability.

Questions, answers and conversation history are not retained by default.
Optional private metadata receipts have byte/row/age limits. Private semantic
review packages bind claims, context spans, source dependency declarations and
observation clocks; supplied reviewer labels do not authenticate identity or
verify factuality. The local directory correction ledger similarly records
explicit role decisions and reopens review on changed source bytes; seed links
and generation times do not establish field currency.

## Temporal and generated evidence

Event aggregation separates occurrence, publication, upload and generated times.
Bounded recurrence expansion preserves UID/recurrence identity, exclusions,
cancellations and time basis, with explicit unsupported-rule diagnostics. Floating
or unresolved times retain uncertainty; all-day ICS export does not invent a
source timezone. Document attachment/context dates cannot independently schedule
a meeting. Activity records deduplicate snapshots and separate revisions;
sampling receipts declare expected/observed/missing checks and source identities.
Insufficient or changed sampling yields an explicit noncomparable trend, not a
civic or hazard-frequency conclusion.

Code indexing activates one staged complete collection bound to corpus bytes,
configuration and actual vector IDs. Transcript ownership/reindex requirements
remain separate. Normal and streaming chat share context construction; incomplete
streams cannot enter successful history. Generated answers remain unverified.
The [dated native RAG receipt](evidence/rag-native-2026-10-01.json) records 6/6
applicable listed-section retrieval hits and 6/8 mechanical disposition matches
with zero errors. Its sixteen-case context replay generated 16/16 answers and
matched 14/16 expected diagnostics; mismatch records remain visible. These are measured
protocol/context observations; semantic support, independent corroboration, legal
currency and useful civic decisions remain unassessed without independent review.

## Publication and verification

Publication chooses one complete verified municipal bundle or the whole reviewed
seed. Failed current acquisition cannot mix individual seed/live core files.
Directory, events, analytics and monthly producers retain exact input,
transformation/configuration and output receipts separately from municipal
eligibility. Public Pages captures approved producer/seed/core bytes and renders
from reconstructed private roots, with public hash commitments and private local
replay archives. A hash or deterministic replay establishes byte identity and
transformation reproducibility; it does not establish source interpretation,
legal authority, semantic support or complete coverage.

Per-family public DTOs and the whole-tree scanner reject private data, credential
URL aliases/fragments, executable protocols and unknown copied artifacts. Available
directory exports replay their actual seed. Sitemap provenance binds the template
bytes consumed and recorded exporter mtime date; it accepts same-byte templates
in another checkout without claiming that mtime is content-change history. Strict
bounded XML parsing rejects extra, malformed and unparsed sitemap elements.
Staged activation, previous-state retention and restart recovery preserve complete
publication editions. Legitimate empty feeds remain empty and valid.

The authoritative gate runs structural contracts, current documentation drift,
strict application/test types, manuscript checks, geo-contract rebuild, fenced
plain/covered suites and actual-line coverage. Both suite runs check output fences
in `finally`, including failure and timeout. Fixtures use isolated roots and real
local HTTP/process/browser boundaries. Native populated GUI, model/vector services,
container restart, exact exported Pages viewports, PDF/HTML rendering and external
consumer checks remain separately named evidence. Hosted workflow success, remote
commit identity and live-site bytes require their own release-specific receipts.

## Remaining acceptance

The open backlog is limited to real opted-in notification delivery, actual private
Pulse/external consumer behavior, persistent production operation, independent
semantic/legal review, source-specific local access and representative field/
calendar/sampling coverage, and separately owned release/research reproduction.
Completed implementation scopes are absent from TODO. Neither a software release
nor aggregate test counts substitute for these external or interpretive facts.
