# Manuscript instructions

Edit the numbered Markdown source files, `config.yaml`, `preamble.md`,
`references.bib`, and `claim_ledger.json`. Do not edit `output/manuscript/`;
it is generated by the hydration command.

Every numbered section begins with an H1 and a stable section label. Use the
Pandoc citation form `[@citation_key]`, equation labels such as
`{#eq:label}`, table labels such as `{#tbl:label}`, and section references
such as `@sec:methods`. Do not use raw LaTeX citation or reference commands.

Run `bun run manuscript:check` after structural edits. Run `bun run analytics`
and then `bun run manuscript:hydrate` when snapshot values change. Run the
repository gate before publication. Claims about source state, summary
provenance, and surface parity must remain separate from claims about safety,
legal sufficiency, source completeness, or LLM factuality.
