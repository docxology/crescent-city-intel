Section Dependency Graph

Every internal § citation between code sections, drawn as arrows from the citing section to the cited one. Authorities are the sections the rest of the code leans on; hubs reach furthest out. Repeat citations make an arrow heavier, never more numerous, and a section citing itself is counted but never drawn. Enter a section ID to draw one section's neighborhood.

Corpus Word Frequency

Word counts over the municipal code, using the same word-matching rules as the search index — so a term shown here is a term search would have matched. Salience rewards words that appear often here but rarely elsewhere: boilerplate appearing in every section scores zero however often it occurs.

Section Longevity & Amendment Age
