Section Dependency Graph

Every internal § citation between code sections, as a directed graph. Authorities are the sections the rest of the code hangs off; hubs reach furthest out. Corpus Word Frequency

Term counts over the municipal code, using the same tokeniser, stemmer, and stop list as the search index — so a term shown here is a term search would have matched. Salience is tf·idf: boilerplate appearing in every section scores zero however often it occurs.
